# JD Global Clone

A modern, high-performance clone of the JD Global e-commerce platform built using React and Vite.

## Project Structure

This repository contains both the frontend application and the backend directory:

- `/frontend`: The React application powered by Vite.
- `/backend`: The server environment (currently empty, ready for initialization).

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm

### Installation & Setup

1. **Navigate to the frontend directory:**
   ```bash
   cd frontend
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **View the application:**
   Open your browser and navigate to the local URL provided by Vite (usually `http://localhost:5173`).

## Features
- **Modern Architecture**: Component-driven architecture using React.
- **Premium Aesthetics**: High-end styling with CSS variables, smooth micro-animations, and glassmorphism elements.
- **Interactive UI**: Working cart state counter and hover effects.
- **Responsive Layout**: Designed to look great on desktop and mobile screens.
